1. Deskripsi Aplikasi
Aplikasi Kasir merupakan aplikasi berbasis web yang dibuat untuk membantu proses pengelolaan penjualan dan transaksi. Aplikasi ini memiliki dua hak akses pengguna, yaitu Admin dan Petugas, yang masing-masing dapat mengelola data serta melakukan transaksi penjualan.

2. Tujuan Pembuatan
Tujuan dari pembuatan aplikasi ini adalah:

- Mempermudah proses transaksi penjualan.
- Membantu pengelolaan data produk dan pelanggan.
- Mempermudah pencatatan dan pencarian riwayat transaksi.
- Mengurangi kesalahan dalam proses pencatatan transaksi.

3. Fitur Aplikasi
 Dashboard Admin
Admin dapat mengakses dashboard untuk melihat dan mengelola data aplikasi.

 Dashboard Petugas
Petugas dapat mengakses dashboard untuk menjalankan aktivitas pengelolaan data dan transaksi.

 Manajemen Produk
- Menambahkan produk.
- Mengedit data produk.
- Menghapus produk.

 Manajemen Pelanggan
- Menambahkan pelanggan.
- Mengedit data pelanggan.
- Menghapus pelanggan.

 Transaksi
- Melakukan transaksi penjualan.
- Mengelola data transaksi.
- Melihat riwayat transaksi.
